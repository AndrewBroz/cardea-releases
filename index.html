Cardea

Browse with intention.

Before you open a distracting site, Cardea asks you to name your intention. It then runs a session timer and makes the page less distracting. You choose the sites.

The Add to Firefox button needs Firefox on a computer. For Chrome, Edge, or Brave, use the Chrome Web Store link below it.

Add to Firefox

Version 0.8.1 · Firefox 140 or newer, desktop

Using Chrome, Edge, or Brave? Get Cardea from the Chrome Web Store.

Firefox will ask before installing:
  1. Click Continue to Installation.
  2. Click Add.
Signed by Mozilla. Cardea updates itself automatically.
